# Contribute

GTNA is open source and developed in the [GTInfinityAscension](https://github.com/GTInfinityAscension) organisation. You can help without writing code.

| How | Where |
|---|---|
| Report a bug or a wrong page | [issues](https://github.com/GTInfinityAscension/GregTech-Nexus-Addon/issues) |
| Translate the mod or this wiki | [Translating](translating.md) |
| Fix a page | the edit button at the top of every page |
| Write code | [Development setup](setup.md), [Architecture](architecture.md), [Contributing code](contributing.md) |
| Follow what is coming | [Roadmap](../roadmap/index.md) |

Please read the organisation's [Code of Conduct](https://github.com/GTInfinityAscension/.github/blob/main/CODE_OF_CONDUCT.md) and [AI policy](https://github.com/GTInfinityAscension/.github/blob/main/AI_POLICY.md) first.
