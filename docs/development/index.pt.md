# Contribuir

O GTNA é código aberto e é desenvolvido na organização [GTInfinityAscension](https://github.com/GTInfinityAscension). Dá para ajudar sem escrever código.

| Como | Onde |
|---|---|
| Relatar um bug ou uma página errada | [issues](https://github.com/GTInfinityAscension/GregTech-Nexus-Addon/issues) |
| Traduzir o mod ou esta wiki | [Traduzir](translating.md) |
| Corrigir uma página | o botão de editar no topo de cada página |
| Escrever código | [Ambiente de desenvolvimento](setup.md), [Arquitetura](architecture.md), [Contribuir com código](contributing.md) |
| Acompanhar o que vem por aí | [Roadmap](../roadmap/index.md) |

Leia antes o [Código de Conduta](https://github.com/GTInfinityAscension/.github/blob/main/CODE_OF_CONDUCT.md) e a [política de IA](https://github.com/GTInfinityAscension/.github/blob/main/AI_POLICY.md) da organização.
