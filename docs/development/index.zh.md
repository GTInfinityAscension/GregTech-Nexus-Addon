# 参与贡献

GTNA 是开源项目，在 [GTInfinityAscension](https://github.com/GTInfinityAscension) 组织中开发。不写代码也可以帮忙。

| 方式 | 入口 |
|---|---|
| 报告 bug 或页面错误 | [issues](https://github.com/GTInfinityAscension/GregTech-Nexus-Addon/issues) |
| 翻译模组或本 wiki | [翻译](translating.md) |
| 修正页面 | 每页顶部的编辑按钮 |
| 编写代码 | [开发环境](setup.md)、[架构](architecture.md)、[贡献代码](contributing.md) |
| 关注后续计划 | [路线图](../roadmap/index.md) |

请先阅读组织的[行为准则](https://github.com/GTInfinityAscension/.github/blob/main/CODE_OF_CONDUCT.md)和 [AI 政策](https://github.com/GTInfinityAscension/.github/blob/main/AI_POLICY.md)。
