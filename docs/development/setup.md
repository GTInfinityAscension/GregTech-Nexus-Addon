# 🛠️ Setup do Ambiente
## Requisitos
- Java 17 (JDK)
- IntelliJ IDEA (recomendado) + Plugin Minecraft Dev + Lombok
- Git
## Passos
1. Clone o repositorio: `git clone https://github.com/GTInfinityAscension/GregTech-Nexus-Addon.git`
2. Importe como projeto Gradle no IntelliJ
3. Sincronize: `./gradlew build`
4. Rode o client: `./gradlew runClient`
