# GregTech Nexus Addon

<p class="lead">Minecraft 1.20.1 上 GregTech CEu Modern 的附属模组：把蒸汽时代变成真正的工厂阶段，提供无线蒸汽与无线 EU、AE2 自动化，以及从蒸汽时代到终局的 170 个多方块。</p>

[安装](getting-started/installation.md){ .md-button .md-button--primary } [浏览多方块](gameplay/machines/catalog/index.md){ .md-button }

<div class="feature-grid" markdown>

<div class="feature-card" markdown>
### 蒸汽时代
带并行的大型蒸汽机器、无需能量的原始机器、液压部件以及蒸汽电梯。

[:octicons-arrow-right-24: 蒸汽时代](gameplay/machines/steam-age.md)
</div>

<div class="feature-card" markdown>
### 无需管道和导线
每位玩家一个蒸汽池和一份 EU 余额，在任何地方都能使用。

[:octicons-arrow-right-24: 无线蒸汽](gameplay/systems/wireless-steam-network.md) · [Nexus 能量](gameplay/systems/nexus-energy-network.md)
</div>

<div class="feature-card" markdown>
### AE2 自动化
样板总成可为任何多方块保存样板、电路、催化剂和机器模式。

[:octicons-arrow-right-24: ME 样板总成](gameplay/systems/pattern-buffers.md)
</div>

<div class="feature-card" markdown>
### 170 个多方块
移植自 GT: Not Leisure、GregTech Odyssey、GregTech Leisure、GT: New Horizons 和 Twist Space Technology，另有 GTNA 原创机器。每个都有专页。

[:octicons-arrow-right-24: 图鉴](gameplay/machines/catalog/index.md)
</div>

<div class="feature-card" markdown>
### 终局
诸神之锻炉、鸿蒙之眼、玻色-爱因斯坦凝聚态、太空电梯、纳米锻炉和戴森球，附全部公式。

[:octicons-arrow-right-24: 系统](gameplay/systems/index.md)
</div>

<div class="feature-card" markdown>
### 面向整合包
KubeJS 绑定、可用于任何多方块的辅助模块、平衡文件以及研究引擎。

[:octicons-arrow-right-24: KubeJS API](development/api/kubejs.md)
</div>

</div>
