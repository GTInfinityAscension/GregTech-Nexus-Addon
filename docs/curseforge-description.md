<h1>GregTech Nexus Addon</h1>
<p><strong>The Nexus of Steam &amp; Steel.</strong> Build a factory that grows from steam and hydraulics into modular industrial processing and large AE2 systems. GTNA expands GregTech CEu Modern for Minecraft 1.20.1 with machines, logistics and automation tools that work together across progression.</p>

<h2>What you can build</h2>
<ul>
  <li><strong>Wireless steam factories:</strong> connect boilers and multiblocks through steam input and output hatches, monitor network flow, and use the optional HUD.</li>
  <li><strong>Steam and hydraulic production:</strong> large steam machines, a Steam Elevator with specialized modules, and hydraulic manufacturing.</li>
  <li><strong>Modular multiblocks:</strong> attach extension structures to supported machines to unlock more abilities, and use the Nexus Structure Terminal to preview and build them.</li>
  <li><strong>AE2 automation:</strong> ME Pattern Buffers support multiple recipe modes; the Nexus ME Hypercore brings large scale crafting CPU integration.</li>
  <li><strong>Specialized hatches:</strong> Thread, Accelerate, Overclock, Parallel and Output Boost parts let supported machines handle demanding recipes.</li>
  <li><strong>More processing options:</strong> integrated ore processors, the Universal Factory and other electric or no-energy multiblocks.</li>
</ul>

<h2>For modpack creators</h2>
<p>GTNA includes a KubeJS integration for custom machine definitions and multiblock extensions, plus a Java API. Optional integrations depend on the relevant mods being installed.</p>

<h2>Compatibility</h2>
<p><strong>Minecraft 1.20.1 · Forge · GregTech CEu Modern 7.5.3+</strong>. GTNA's AE2 features use Applied Energistics 2 and ExtendedAE. Check the file dependencies before installing; optional content uses its respective mod.</p>
