# 纳米锻炉

![纳米锻炉](../../assets/machines/nano_forge.webp){ loading=lazy }

以海量能量制造纳米机器人。移植自 GT: New Horizons。

## 等级

任意输入总线中的纳米机器人决定锻炉等级，并且**永不消耗**。每个等级还需要更大的结构；额外部分是[辅助模块](modules.md)，因此 JEI/EMI 会把每个等级显示为单独的预览页。

| 等级 | 总线中的纳米机器人 |
|---|---|
| 1 | 碳纳米机器人 |
| 2 | 中子素纳米机器人 |
| 3 | 超越金属纳米机器人 |
| 4 | 磁物质纳米蜂群 |

低于锻炉等级的配方获得**完美超频**。

## 第 4 级：磁物质

当总线中有与配方产物相同的纳米机器人时，锻炉会抽干仓中**全部**熔融磁物质，并将其转化为并行：

```
并行 = 磁物质 / (288 / 2^(4 − 配方等级))
时长 × 0.9999^并行
```
