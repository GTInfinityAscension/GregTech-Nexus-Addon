# 玻色-爱因斯坦凝聚态

![玻色-爱因斯坦凝聚态纠缠装置](../../assets/machines/bec_generator.webp){ loading=lazy }

一套移植自 GT: New Horizons 的后期合成网络。五个多方块共享**凝聚态**（一种由熔融金属制成的奇异资源），并与纳米机器人一起完成凝聚态装配配方。

## 网络

机器之间通过**玻色-爱因斯坦凝聚态导管**相连。给导管染色即可把一个网络拆成多个。凝聚态像导线中的能量一样属于网络资源，不会停留在仓室中。

| 机器 | 作用 |
|---|---|
| [纠缠装置](../machines/catalog/bec_generator.md) | 把熔融金属和流体转化为凝聚态，同时处理仓中所有流体。并行会填满可用 EU/t；循环时长等于最慢的配方。网络没有空间时凝聚态会被销毁 |
| [约束场](../machines/catalog/bec_storage.md) | 储存凝聚态（见下文） |
| [麦克斯韦门](../machines/catalog/bec_diode.md) | 让凝聚态单向流动，可按类型过滤，过滤器由流体输入仓设定。运行时消耗 1A UIV，关闭时阻断网络 |
| [观测阵列](../machines/catalog/bec_assembler.md) | 通过视线连接器为传送节点提供纳米机器人、EU 和凝聚态。一个阵列可服务多个节点。纳米机器人等级取其总线中的最低等级；最多计入 30,720 个 |
| [传送节点](../machines/catalog/bec_io_node.md) | 用自己的总线执行配方（见下文） |

## 合成

传送节点执行**凝聚态装配**配方：

- 每个物品槽依次要求一种等级的纳米机器人。
- 额外的纳米机器人线性加快合成。等级高于要求的纳米机器人会使速度降低 `2^(提供等级 − 要求等级)` 倍。
- 凝聚态可在合成结束前任何时候到达。结束时仍缺少则合成失败。
- 出现超过 3 种配方未要求的凝聚态时，合成同样失败。
- 不能超频。最小/最大并行和速度除数在节点参数中设置。
- 观测阵列缺少 EU 时节点会停工。

## 储存

在**约束场**中，1 点场强储存 1 mB，消耗 1 EU/t。注入的凝聚态按容量分配到各个约束场。超出容量时，每秒保留每种凝聚态的 9/10。

!!! danger "断电"
    约束场断电或被关闭时，会**销毁**其中储存的全部凝聚态。
