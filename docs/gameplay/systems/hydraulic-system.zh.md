# 液压组件

GTNA 的蒸汽时代有自己的合成组件：液压部件。在 GTNA 蒸汽多方块、无线蒸汽仓和蒸汽电梯的配方中，它们承担电动马达、活塞和泵的角色。

| 组件 | 用于 |
|---|---|
| 液压马达 | 其他液压部件；石材超级加热器；大型蒸汽洗矿机、搅拌机、离心机和热力离心机 |
| 液压活塞 | 液压机械臂；大型蒸汽锻造锤、压缩机、提取机、车床、压模器和筛选机 |
| 液压泵 | 液压蒸汽接收器；大型蒸汽提取机、洗矿机和浸洗机；原始蒸馏塔；蒸汽裂化机 |
| 液压机械臂 | 蒸汽制造厂；大型蒸汽切割机；蒸汽电梯的温室和蜜蜂模块 |
| 液压传送带 | 大型蒸汽合金炉、浸洗机、切割机、卷板机、压模器和线材轧机 |
| 液压调节器 | 无线蒸汽仓；仙人掌奇观；蒸汽电梯 II、III 级模块 |
| 液压蒸汽发生器 | 蒸汽电梯 III 级模块；紧凑型超压反应堆 |
| 液压蒸汽喷射器 | 液压蒸汽发生器；蒸汽电梯及其 I 级模块；蒸汽物品仓库 |
| 液压蒸汽接收器 | 蒸汽电梯模块；古旧蒸汽门虚空采矿机 |
| 精密蒸汽组件 | 大多数大型蒸汽多方块（破碎机、熔炉、锻造锤、压缩机、提取机、洗矿机……） |

## 两种制作方式

- **工作台：**最初的部件有有序合成配方，材料为粘土化合物板、铁杆、铁转子、青铜齿轮和微型青铜流体管道。
- **液压制造：**在[蒸汽制造厂](../machines/catalog/steam_manufacturer.md)中制作同样的部件。它使用蒸汽（每个并行 16 mB/t），一次可以做很多个。钢制无线蒸汽仓和蒸汽电梯也在这里制作。

JEI/EMI 在*液压制造*分类下列出全部配方。
