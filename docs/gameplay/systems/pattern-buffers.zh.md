# ME 样板总成

样板总成是一种多方块部件，存放 AE2 处理样板，同时充当输入总线、输入仓和样板供应器。把它装在 GTCEu 或 GTNA 的多方块上，AE2 就能直接向它下达合成任务。需要 Applied Energistics 2。

## 四种总成

| 总成 | 样板槽位（默认） |
|---|---:|
| ME迷你样板缓存 | 9 |
| ME样板总成 | 21 |
| ME高级样板缓存 | 32 |
| ME终极样板缓存 | 72 |

界面每页显示 90 个槽位。槽位数来自 `config/gtna/balance/pattern_buffers.json`（每种 1 到 540），在启动时读取。

**升级卡**可原地把总成升级为下一级，保留样板、槽位设置和已存物品：样板缓存扩展卡（21 槽）、样板缓存精密卡（32 槽）、样板缓存晋升卡（72 槽）。**复制卡**和**剪切卡**用于搬运整套配置：潜行右键一个总成取出配置，右键另一个总成粘贴。拆下的总成会保留样板和槽位数据。

## 单槽设置

用鼠标中键点击样板槽位进行编辑：

- **电路：**只对该样板生效的编程电路。工具页的*嵌入电路*会把同一电路写入所有样板（可选择跳过已有电路的样板）。
- **催化物品与流体：**留在槽位中，永不消耗，例如模具、透镜或催化流体。
- **幽灵物品与流体：**按你设定的数量附加到样板上的额外输入。
- **首选模式：**对拥有多种配方类型的多方块，指定该样板运行的模式。开启 `machines.bufferDrivenMachineMode`（默认开启）时，总成会在 GTCEu 机器空闲时切换其模式，因此一台大型切割机可以用同一个总成既切割又车削。
- **配方缓存：**总成会记住每个槽位匹配到的配方。用脚本修改配方后请清除缓存。

顶部的**总成模式**可把整个总成限制为一种配方类型。

## 相关部件

| 部件 | 作用 |
|---|---|
| ME样板总成镜像 | 让另一个多方块使用别处总成中的样板。用数据棒潜行右键总成，再右键镜像。仅限同一维度，且总成所在区块必须加载 |
| ME输出缓存 | 输出总线与输出仓合一：把物品和流体直接送入 ME 网络。内部缓存每种物品或流体最多 9.2 × 10¹⁸，配方不会因输出已满而停工 |
| Nexus合成样板仓 | 为 [Nexus装配锻炉](../machines/catalog/nexus_molecular_forge.md) 接收工作台合成样板 |
| ME存储访问仓 / ME大型存储访问仓 | 把 [ME存储器](../machines/catalog/me_storage.md) 多方块连接到 AE2 网络；大型版本可计数超过 64 位 |

## 提示

- 每条生产线一个总成，比一个巨型总成更好管理：AE2 的样板访问终端会分别列出每个总成。总成也可以设置为在该终端中隐藏。
- 样板没有反应时，打开该槽位查看：最常见的原因是缺少电路或首选模式错误。
- 整合包调低槽位数时，GTNA 会让世界中已有的总成保留原来的大小（`pattern_buffer_capacity_history.json`）。请把这个文件与世界一起保存。
