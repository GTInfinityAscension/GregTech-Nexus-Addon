# 模块与结构终端

## 辅助模块 {#auxiliary-modules}

部分多方块可以接受**辅助模块**：在主体旁边额外建造的可选结构，由同一个控制器检测。没有模块时机器也能成型。模块成型后，其中的仓室会并入机器，从而解锁新的仓室类型或新的配方类型。控制器会显示*已成型模块：n / 总数*，JEI/EMI 会把每个模块作为结构预览的额外一页，物品提示会列出模块解锁的内容。

| 机器 | 模块提供 |
|---|---|
| 电力高炉（GTCEu） | 加速仓与额外的有线能源仓 |
| 液化炉 | 并行仓与加速仓 |
| 蒸发塔 | 并行仓与加速仓 |
| 寒冰冷冻机 | 雾化冷凝配方、一个加速仓以及最多六个额外能源仓 |
| 部件组装机 | 两种扩展形态（普通与加宽），提供更多仓室 |
| 大型火箭引擎涡轮 | 2 倍输出、+20% 效率、2 倍转子损耗、最多三个额外能源输出仓 |
| 超临界蒸汽涡轮 | 与大型火箭引擎涡轮模块相同的加成 |
| 狂飙号巨型聚变反应堆 | 四个等级模块（MK-II 至 MK-V）以及一个跨配方模块 |
| 纳米锻炉 | 第 2、3、4 级结构 |

整合包可以用 KubeJS 为任何多方块（GTNA 或其他模组的）添加模块：见 [`GTNAServerEvents.subPatterns`](../../development/api/kubejs.md#auxiliary-modules)。自 GTNA 0.6.1 起，模块注册表位于 GTIA Lib 中。

## Nexus结构终端 {#nexus-structure-terminal}

用于搭建大型多方块的工具。

- 对空气**右键**：打开设置。
- 对控制器 **Shift + 右键**：在其周围建造结构，包括模块。

| 设置 | 效果 |
|---|---|
| 按等级选择方块 | 按类别选择要放置的线圈、外壳或玻璃等级 |
| 重复次数（0–1000） | 可扩展结构的层数，例如蒸馏塔 |
| 模块搭建（0–100） | 要建造的模块层数 |
| 无仓室模式 | 跳过总线和仓室，方便自己手动放置 |
| 替换模式 | 把已放置的方块（例如其他等级的线圈）换成你选择的方块；旧方块放回背包 |
| 镜像搭建 | 建造结构的镜像版本 |
| 拆除模式 | 清除结构要求为空气的位置上的方块 |

生存模式下终端从你的背包取方块。用它右键 AE2 无线访问点后，在范围内还可以从该 ME 网络取方块。
