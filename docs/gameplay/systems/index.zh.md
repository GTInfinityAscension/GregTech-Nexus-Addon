# 系统

把 GTNA 各台机器连接起来的机制，大致按你遇到它们的顺序排列。

| 系统 | 阶段 | 简介 |
|---|---|---|
| [无线蒸汽网络](wireless-steam-network.md) | 蒸汽 | 每位玩家一个蒸汽池，无需管道 |
| [液压组件](hydraulic-system.md) | 蒸汽 | 蒸汽时代的合成部件 |
| [模块与结构终端](modules.md) | 全阶段 | 可选的额外结构，以及替你搭建结构的工具 |
| [Nexus 能量网络](nexus-energy-network.md) | LV 起 | 以通量矩阵为储能的无线 EU |
| [ME 样板总成](pattern-buffers.md) | 需要 AE2 | 把样板、输入和模式合并到一个多方块部件中 |
| [虚空采矿](void-mining.md) | 蒸汽、EV 及之后 | 无需挖掘即可获得矿石和流体 |
| [研究引擎](research-engine.md) | 由整合包决定 | 整合包可填入自己节点的研究树 |
| [物品特效](item-effects.md) | — | 终局材料的动态图标 |
