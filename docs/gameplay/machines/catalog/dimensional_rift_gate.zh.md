## 说明

打开通往种子维度的裂隙；调节频率、相位与振幅直到裂隙稳定。

- 每个生物群系掉落各自的资源
- 记录的谐音组成和弦，塑造裂隙
- 三个调谐轴决定共振 R
- 时空流体保持裂隙稳定
- 深度锚使产出提升 D^1.5
- 稳定度降到 0 时裂隙坍塌
- 不协和和弦挖得更深，但代价更高
