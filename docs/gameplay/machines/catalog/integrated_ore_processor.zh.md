## 说明

一步完成矿石处理；电路选择七条路线之一。

- 一次完成研磨、洗矿、浸洗、筛选和离心
- 电路1：粉碎 -> 粉碎 -> 离心
- 电路2：粉碎 -> 洗矿 -> 热力离心 -> 粉碎
- 电路3：粉碎 -> 洗矿 -> 粉碎 -> 离心
- 电路4：粉碎 -> 洗矿 -> 筛选 -> 离心
- 电路5：粉碎 -> 浸洗 -> 热力离心 -> 粉碎
- 电路6：粉碎 -> 浸洗 -> 粉碎 -> 离心
- 电路7：粉碎 -> 浸洗 -> 筛选 -> 离心
- 并行来自并行控制仓
