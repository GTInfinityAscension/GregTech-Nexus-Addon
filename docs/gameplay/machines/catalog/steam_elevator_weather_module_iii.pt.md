## Descrição

Queima vapor para mudar o clima para limpo, chuva ou tempestade pelo circuito do controlador.

- O clima dura 3 h
- Custo: 1.000.000 mB de vapor por troca
- Circuito 1: limpo, 2: chuva, 3: tempestade
- Só funciona encaixado num Steam Elevator
