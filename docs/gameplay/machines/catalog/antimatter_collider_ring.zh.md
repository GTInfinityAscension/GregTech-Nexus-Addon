## 说明

把反向旋转的粒子束经增能环加速到主环并对撞，产生奇异粒子。

- 以 5σ 显著性发现粒子即可满产
- 提案解锁更强的磁体与陷阱
- 束流能量：p = 0.3 · B · ρ
- 液氦冷却超导磁体
- 反质子存入彭宁阱（无线 EU）
- 缺少液氦会导致磁体失超
- 陷阱断电会湮灭其中的反物质
