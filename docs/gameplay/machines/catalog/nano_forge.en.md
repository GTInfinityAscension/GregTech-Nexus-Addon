## Description

Nanobots, son. Billions of them. Builds nanites with insane amounts of power; the nanite in any input bus sets the tier.

- Machine Type: Nanite Fabricator
- Perfect overclock on lower-tier recipes
- The tier nanite is never consumed
- Carbon T1, Neutronium T2, Transcendent T3
- MagMatter T4: molten MagMatter adds parallels
- Keep the tier nanite in an input bus
- Each tier needs structural changes
