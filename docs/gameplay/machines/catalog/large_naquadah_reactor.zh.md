## 说明

将硅岩燃料与氢气或等离子体一起燃烧，提供稳定的 UHV 电力。

- 可朝任意方向建造
- 动力仓或激光源仓
- 燃料 + 氢气：2,097,152 EU/t
- 燃料 + 等离子体：524,288 EU/t，持续时间为 32 倍
- 最多 3 个流体输入仓
