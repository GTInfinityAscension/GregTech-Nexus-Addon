## 说明

用能源和钻井液开采矿脉程序，产出粗矿。

- 精确模式：用精华选择矿脉
- 随机模式：无需精华，完整ZPM矿池
- 电路1 = EV基础，电路2 = LuV/ZPM矿脉
- IV起，并行控制仓增加并行
- 每次运行需要钻井液
- EV等级没有并行
