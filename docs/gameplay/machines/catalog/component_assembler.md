## Descrição

Seu primeiro salário não paga nem uma peça dela. Monta lotes de 16 componentes elétricos a partir de materiais e circuitos.

- Tipo de Máquina: Montagem de Componentes
- Extensão: limite de receita IV -> UV + Accelerate
- Extensão 2: Parallel Control e Laser Hatches
- Limite de receita: IV, nunca acima do tier do casing
- Cada upgrade precisa de uma estrutura maior
