## 说明

用自身总线制作凝聚态组装配方；每个物品槽依次需要一个纳米蜂群等级。

- 额外的纳米蜂群线性加速制作
- 参数中可设最小/最大并行和速度除数
- 更高等级的纳米蜂群会减速 2^（提供 - 所需） 倍
- 凝聚态可在结束前任何时候送达
- 无超频
- 结束时缺少凝聚态则配方失败
