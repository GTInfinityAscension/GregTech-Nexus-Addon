# Parallel Control Hatch (UHV+)

GTCEu's Parallel Control Hatches stop at 256 parallel (UV). GTNA continues the line with the same name:

| Hatch | Max parallel |
|---|---:|
| UHV | 1,024 |
| UEV | 4,096 |
| UIV | 16,384 |
| UXV | 65,536 |
| OpV | 262,144 |

They use GTCEu's normal Parallel Hatch slot, so they fit every multiblock that takes a Parallel Hatch, one per machine. With a [Thread Hatch](thread-hatch.md), the parallel is split between the threads.
