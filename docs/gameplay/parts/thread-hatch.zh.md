# 线程仓

让多方块同时运行**不同**的配方。并行仓重复同一个配方；线程仓则增加相互独立的配方位，每个都有自己的计时。

| 仓室 | 额外线程 | 总数 |
|---|---:|---:|
| ZPM | +1 | 2 |
| UV | +3 | 4 |
| UHV | +7 | 8 |
| UEV | +15 | 16 |
| UIV | +31 | 32 |
| UXV | +63 | 64 |
| OpV | +127 | 128 |
| MAX | +255 | 256 |

可以在仓室界面中调低线程数。数值位于 `config/gtna/balance/hatches.json`（`threadHatch`）。

## 适用范围

线程在基于 GTNA **多配方**逻辑、且结构留有该仓位置的机器中生效，例如[工业屠宰场](../machines/industrial-slaughterhouse.md)、集成矿石处理厂及其进阶版、超级蒸馏塔、超维度等泥土锻炉、原始石炉，以及狂飙号巨型聚变反应堆的跨配方模块。整合包可以用 KubeJS 在该基础上制作更多机器。

## 线程如何分配并行

配合并行仓时，并行数会在线程之间平分。例如：UEV 并行控制仓（4,096）加 UV 线程仓（4 个线程），得到 4 个配方，每个 1,024 并行。
