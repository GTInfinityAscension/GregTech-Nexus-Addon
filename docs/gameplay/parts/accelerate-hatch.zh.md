# 加速仓

在常规超频之外，缩短多方块所有配方的时间。移植自 GregTech Odyssey。

| | |
|---|---|
| **等级** | LV 至 MAX |
| **可安装于** | 结构接受它的电力多方块（GTCEu 与 GTNA），以及提供它的[辅助模块](../systems/modules.md) |
| **每台机器** | 一个 |

## 时长

数值为剩余时长占原时长的百分比：

| 仓室 | 时长 | 仓室 | 时长 |
|---|---:|---|---:|
| LV | 50% | UV | 36% |
| MV | 48% | UHV | 34% |
| HV | 46% | UEV | 32% |
| EV | 44% | UIV | 30% |
| IV | 42% | UXV | 28% |
| LuV | 40% | OpV | 26% |
| ZPM | 38% | MAX | 24% |

公式为 `50 − 2 · (等级 − 1)` %。可以在仓室界面中调高该值，最高 100%（无效果）。

## 惩罚

**配方**等级每高于仓室一级，增加 20 个百分点。高等级机器中的低等级配方永远不会受罚。

!!! example
    HV 仓（46%）运行 EV 配方：46% + 20% = 66%。100 刻的配方需要 66 刻。

最终数值保持在 1% 至 100% 之间。数值位于 `config/gtna/balance/hatches.json`（`accelerateHatch`），EU 消耗倍率为 `config/gtna.yaml` 中的 `machines.accelerateHatchEnergyCost`（默认 1.5）。

## 与其他仓室配合

所有效果相乘：`时长 = 基础 × 超频级数 × 加速`。示例见[超频仓](overclock-hatch.md)。
