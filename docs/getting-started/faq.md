# Perguntas frequentes

??? question "Os ícones dos materiais do GTNA aparecem como textura faltando"
    Na 0.5.4 e 0.5.5 os modelos dependiam do RenderBlender. Atualize para a 0.5.6 ou mais nova, que tem render próprio.

??? question "Posso desligar os efeitos dos itens (halo, shaders)?"
    Sim: `config/gtna.json`, seção client: `itemHalo`, `itemGlowEdge`, `itemShaderEffects` e `itemEffectSpeed`.

??? question "A estrutura não forma"
    Use o botão de checagem de estrutura do controlador: ele marca o bloco errado. O JEI/EMI mostra a estrutura camada por camada.

??? question "As receitas estão diferentes do GTNH"
    O GTNA traz receitas padrão funcionais; o balanço é do modpack, que pode trocar tudo pelo KubeJS.

??? question "Preciso do Ad Astra?"
    Não. Sem ele o Elevador a Vapor não viaja e o Olho da Harmonia só tem os planetas do Minecraft.

??? question "Onde reporto um bug?"
    No GitHub do projeto, com o `latest.log` e a versão do GTNA e do GTCEu.
