# 新手上路

GTNA 遵循 GregTech 的电压等级。下表大致是其内容出现的顺序。整合包可以修改所有配方，因此以你所玩整合包的任务书为准。

| 阶段 | GTNA 新增内容 | 阅读 |
|---|---|---|
| 蒸汽 | 大型蒸汽机器、液压部件、大型蒸汽太阳能锅炉、无线蒸汽、无需能量的原始机器、蒸汽电梯 | [蒸汽时代](../gameplay/machines/steam-age.md)、[无线蒸汽网络](../gameplay/systems/wireless-steam-network.md) |
| LV–HV | Nexus 能量网络、工业屠宰场、加速仓、更多加工多方块 | [Nexus 能量网络](../gameplay/systems/nexus-energy-network.md)、[工业屠宰场](../gameplay/machines/industrial-slaughterhouse.md) |
| EV–IV | 电力虚空采矿机与虚空流体钻机、大规模使用样板总成、辅助模块 | [虚空采矿](../gameplay/systems/void-mining.md)、[ME 样板总成](../gameplay/systems/pattern-buffers.md) |
| LuV–UV | 巨型机器、线程仓与超频仓、数据与算力 | [仓室与部件](../gameplay/parts/index.md) |
| UHV–UXV | 太空电梯、纳米锻炉、戴森球、鸿蒙之眼、原创多方块 | [系统](../gameplay/systems/index.md) |
| UIV–MAX | 玻色-爱因斯坦凝聚态、诸神之锻炉、恒星约束舱 | [诸神之锻炉](../gameplay/systems/forge-of-gods.md) |

## 实用习惯

- **阅读控制器提示。**每台 GTNA 机器都会说明用途、并行和特殊规则；最后一行注明它移植自哪个模组。
- **建造前先在 JEI/EMI 中查看结构。**把鼠标悬停在某个位置上，即可看到可放置的方块和仓室。
- **让终端帮你建造。**[Nexus结构终端](../gameplay/systems/modules.md#nexus-structure-terminal)可以替你放置大型结构。
- **遇到新机器就查图鉴：**[168 个页面](../gameplay/machines/catalog/index.md)，附方块清单。
- **尽早使用无线网络。**无需管道和导线的蒸汽与 EU 可以省去大量搭建工作。
